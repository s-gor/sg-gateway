# Руководство пользователя SG-Gateway

## System

Показывает память, диск, CPU, load average, версии и состояние служб. С этой страницы можно перейти к диагностике и Maintenance.

## Clients

Клиент — логическая запись пользователя. Устройство — отдельный набор реквизитов.

Рабочий порядок:

1. создать клиента;
2. добавить устройство;
3. выбрать доступные профили;
4. проверить доступы;
5. скопировать общую subscription или отдельный профиль;
6. при необходимости временно отключить устройство или клиента.

## Connections

Здесь настраиваются серверные профили AmneziaWG, Xray и Mihomo. Нажатие на карточку или раскрытие «Дополнительно» само по себе ничего не применяет.

## Outbounds

- `Direct` — выход через публичный IP сервера;
- `WARP` — выход через Cloudflare WARP;
- `Block` — запрет трафика.

## Routing

Выбирает действие для локальной сети, российских ресурсов, рекламы, заблокированных ресурсов и остального трафика. GeoFiles находятся на соседней вкладке.

## Maintenance

Резервные копии, журналы, диагностика, обновления и восстановление.

## Security

Пароль, HTTPS, сертификат и состояние публичного доступа.

## Help

Краткие инструкции по каждому разделу и типовым операциям.
