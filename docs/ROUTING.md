# Routing и GeoFiles

## Действия

SG-Gateway использует три реальных действия:

- `Direct`;
- `WARP`;
- `Block`.

## Базовые схемы

Панель предлагает готовые основы и пользовательский режим. Ручное изменение переводит схему в пользовательское состояние.

## Российская маршрутизация

Можно выбрать набор доменных категорий или сайты и IP, затем назначить `Direct`, `WARP` или `Block`.

## GeoFiles

GeoFiles применяются только связанной парой:

```text
geoip.dat
geosite.dat
```

Поддерживаются встроенные и внешние источники, пользовательские HTTPS-адреса, загрузка двух файлов и локальные пути.

## Безопасное применение

1. файлы загружаются в staging;
2. проверяются размеры, SHA-256 и категории;
3. строится полный будущий Routing;
4. строится полный будущий Xray config;
5. запускается `xray run -test`;
6. только после успеха изменяются live-файлы;
7. при ошибке выполняется rollback.

Отсутствующие категории не удаляются автоматически из пользовательских правил.
