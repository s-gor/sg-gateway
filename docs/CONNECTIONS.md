# Connections и клиентские профили

## AmneziaWG

SG-Gateway использует внешний UDP-порт `585`. Настройки сервера включают адрес, DNS, ключи и параметры профиля. Для каждого устройства создаётся отдельная клиентская конфигурация.

## Xray

### VLESS Reality TCP

Классический TCP/Reality-профиль с XTLS Vision.

### VLESS XHTTP Reality

Клиентская ссылка содержит XHTTP mode, VLESS Encryption и XMUX для РФ. Сервер остаётся в `auto`.

### VLESS XHTTP TLS

Требует готового HTTPS-домена. Клиентская ссылка содержит XHTTP mode, VLESS Encryption и тот же XMUX-профиль.

### Hysteria 2

Использует QUIC/UDP и TLS. Salamander FinalMask включается отдельно и проходит полную проверку candidate.

## XMUX для РФ

Профиль применяется постоянно к обоим XHTTP-профилям:

```json
{
  "maxConcurrency": 0,
  "maxConnections": 6,
  "cMaxReuseTimes": 0,
  "hMaxRequestTimes": "600-900",
  "hMaxReusableSecs": "1800-3000",
  "hKeepAlivePeriod": 0
}
```

Эти значения добавляются в `extra.xmux` клиентских ссылок. Они не записываются в серверный inbound.

## Mihomo и sing-box

Mieru обслуживается Mihomo. AnyTLS и TUIC v5 обслуживаются отдельным
`sing-box`.

Блок остаётся полноширинным, чтобы параметры трёх протоколов не сжимали друг
друга. При применении каждый движок сообщает собственный результат.

Ошибка Mihomo или sing-box больше не откатывает каталог клиентов, Xray,
AmneziaWG или установку панели. Сохранённые реквизиты используются для
формирования персональных ссылок и subscription.

## Фактическое состояние Mihomo

Переключатели Mieru, AnyTLS и TUIC v5 управляют реальными listener. После применения выключенный профиль удаляется из live-конфигурации, его порт перестаёт слушаться, а клиентские ссылки и subscription не выдают этот профиль как доступный. Сохранённые реквизиты не удаляются и используются при повторном включении.
